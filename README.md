# Скорость скачивания

Скрипт `index.js` последовательно скачивает URL, читает тело потоком и печатает среднее время, общий объём и скорость.

Зависимости не нужны. Достаточно Node.js.

## Запуск

```bash
node index.js https://example.com/large.jpg
node index.js https://example.com/large.jpg 5
```

Второй аргумент — число запросов от 1 до 1000. Без него выполняется 10.

## Единицы

- среднее время: **мс**
- объём: **МиБ** (1 МиБ = 1024² байт)
- скорость: **МиБ/с** — общий объём / суммарное время всех запросов
- индикация во время запроса: **байты** (`B`), одна строка, не чаще раза в 200 мс

В объём входят байты тела ответа в том виде, в каком они пришли по сети. `gzip` и `br` не распаковываются. Заголовки HTTP и служебные байты TLS не входят. Служебные байты `Transfer-Encoding: chunked` в объём не входят.

Успешный ответ — только статус 200–299. Редирект, 404, 500 и любой другой код, а также сетевая ошибка, печатают одну строку в stderr и завершают процесс с кодом 1. Итог при этом не выводится. Простой сокета дольше 30 с заканчивается так же: это таймаут бездействия, а не предел длительности загрузки.
